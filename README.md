# ساند بوينت العالمية - واتساب بوت 🤖

بوت واتساب رسمي لشركة **ساند بوينت العالمية للمقاولات** مقرها الدمام، المنطقة الشرقية، المملكة العربية السعودية.

## 💬 دعم 7 لغات

- العربية (🇸🇦) - اللهجة السعودية/الخليجية الصارمة
- English (🇬🇧)
- اردو / Urdu (🇵🇰)
- नेपाली / Nepali (🇳🇵)
- বাংলা / Bengali (🇧🇩)
- हिंदी / Hindi (🇮🇳)
- Tagalog / Filipino (🇵🇭)

## المتطلبات

- Node.js 18+ 
- npm أو yarn

## التثبيت

```bash
# تثبيت التبعيات
npm install

# تشغيل البوت
npm start

# أو للتطوير مع المراقبة التلقائية
npm run dev
```

## الاستخدام

1. شغل البوت: `npm start`
2. سيظهر رمز QR في التيرمينال
3. امسح الرمز باستخدام تطبيق واتساب على هاتفك (الإعدادات > الأجهزة المرتبطة > ربط جهاز)
4. البوت جاهز لاستقبال الرسائل!

## تدفق المحادثة

البوت يدعم تدفق محادثة متعدد اللغات مع دعم 7 لغات:

1. **اختيار اللغة** - يبدأ كل محادثة بعرض قائمة 7 لغات
2. **القائمة الرئيسية** - 5 خيارات حسب اللغة المختارة:
   - **عميل جديد** - يطلب نوع العقار، المساحة، والحي
   - **مقاقد/مورد** - يطلب الملف التجاري، الاسم، والتخصص
   - **باحث عن عمل** - يسأل عن المهنة ثم يوجه حسبها (CV للمهندسين، صور للعمال)
   - **ملف الشركة** - يرسل معلومات مفصلة عن الشركة
   - **بيانات التواصل** - يرسل العنوان والأرقام والساعات

## ملامح مهمة

- ✅ دعم 7 لغات كامل (عربي، إنجليزي، أردو، نيبالي، بنغلاهي، هندي، تاغلو)
- ✅ مضادات حماية من الحظر (تأخير عشوائي 2-5 ثوانٍ + حالة كتابة)
- ✅ سلوك إنساني طبيعي (إرسال "جارٍ الكتابة..." قبل كل رد)
- ✅ **دعم رفع الملفات** - PDF، صور، وفيديوهات (للـ CV والملفات التجارية)
- ✅ تدفق محادثة موجه حسب المهنة (مهندس → CV، عامل → صور أعمال)
- ✅ التحقق من أرقام الجوال السعودية تلقائياً
- ✅ تخزين كل البيانات محلياً في `users.json`
- ✅ إعادة اتصال تلقائية عند قطع الاتصال

## هيكل الملفات

```
whats-sandpoint/
├── index.js           # نقطة الدخول الرئيسية
├── package.json       # تبعيات المشروع
├── users.json         # قاعدة بيانات المستخدمين المحلية
├── session.json       # جلسة واتساب (يتم إنشاؤها تلقائياً)
├── auth_info/         # بيانات المصادقة (يتم إنشاؤها تلقائياً)
└── .env.example       # متغيرات البيئة
```

## ملاحظات هامة

- لا تشارك مجلد `auth_info/` أو ملف `session.json` مع أي شخص
- عند أول تشغيل، سيُطلب مسح رمز QR
- البوت يعمل في وضع `module` (ES Modules)
